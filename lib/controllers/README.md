# Controllers

Folder ini disiapkan sesuai PRD untuk phase 3: penghubung antara view, service,
state aplikasi, serta perhitungan streak. Sampai phase 2, input form dan
daftar Dashboard dikelola dengan `StatefulWidget` dan `setState()`.
Dashboard memuat ulang daftar lewat `HabitService` setelah perubahan berhasil
disimpan. Provider/Riverpod dan controller khusus akan diperkenalkan di phase 3.
